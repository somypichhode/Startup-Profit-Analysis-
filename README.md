# Startup-Profit-Analysis-
A data-driven project analyzing startup spending across R&amp;D, Administration, and Marketing to predict profitability using MySQL, Excel (Regression Analysis), and Power BI

## 📌 Project Objective
The objective of this project is to analyze startup spending data and understand its impact on overall Profit[cite: 1]. The project utilizes regression analysis to identify the mathematical relationships between R&D Spend, Administration, Marketing Spend, and Profit[cite: 1]. Additionally, Power BI is used to visualize the dataset and derive meaningful, actionable business insights[cite: 1].

## 🧰 Dataset and Tools
**Dataset Features:**
* R&D Spend[cite: 1]
* Administration[cite: 1]
* Marketing Spend[cite: 1]
* State[cite: 1]
* Profit[cite: 1]

**Tech Stack / Tools Used:**
* **MySQL:** Used for data extraction and secure data storage[cite: 1].
* **Microsoft Excel:** Utilized for conducting regression analysis and profit prediction[cite: 1].
* **Power BI:** Deployed for data visualization and building an interactive dashboard[cite: 1].

## 📊 Regression Analysis & Results
The statistical modeling yielded a high R-Square value of **0.950746**, which means the model successfully explains most of the variation in Profit based on the given spending features[cite: 1]. 

**Coefficients:**
* **R&D Spend Coefficient:** 0.805715[cite: 1]
* **Administration Coefficient:** -0.02682[cite: 1]
* **Marketing Spend Coefficient:** 0.027228[cite: 1]

*Note: The regression equation was also successfully used to predict profit combinations, resulting in highly accurate forecasts (e.g., predicted profits of 70,037.62 and 70,554.99)[cite: 1].*

## 💡 Key Insights
* **R&D Spend** shows a strong positive correlation with Profit[cite: 1].
* **Marketing Spend** also appears to positively impact profit, though to a lesser degree than R&D[cite: 1].
* **Administration Costs** have little to no measurable effect on overall profit[cite: 1].
* Profits are well-balanced across the states of New York and Florida[cite: 1].
